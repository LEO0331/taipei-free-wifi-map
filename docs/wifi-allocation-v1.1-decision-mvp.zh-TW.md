# 公共 Wi-Fi 地理證據驗證與實驗性配置研究 v1.1

## 1. 政策問題

在有限現場查核名額下，哪些官方公共設施紀錄值得進一步調查？本研究結合官方區界、設施座標假設與已公布熱點位置，建立可重現的幾何近鄰實驗。名額是調查能力，並非建置預算、設備配置指令或居民服務改善人數。

## 2. 範圍及與 v1.0 的關係

既有模式 A 的來源對帳、分級、策略、5／10／全部名額及匯出保留。歷史方法 `wifi-allocation-evidence-review-v1`、快照 `wifi-policy-c250791e7736ed5bca2882ea` 與 SHA-256 `91b28d7b375e7fb14ee42bfbe179d792c9e0ed0992f273582dd1e03e6bac8a82` 不被覆寫；原探索器仍為 3,297 列。v1.1 使用獨立路徑 `public/data/wifi-policy/geographic-v1.1/`，延遲載入模式 B。模式 C 仍不可用。沒有後端、即時監測、住址地理編碼或 Google Maps JavaScript API。

## 4. 來源座標參考系證據

E 的原始 PRJ 宣告 TWD97／TM2 121 分帶，並與 EPSG:3826 定義相符。瀏覽器與 GeoJSON 使用 EPSG:4326 的經度／緯度。B、D 欄位雖為經緯度且數值合理，仍未找到足以確認原始基準與精度的來源宣告。C 的座標 X／Y 未宣告 CRS，使用 EPSG:3826 是研究假設。E 的 PRJ 不能替 C 證明相同基準。

## 5. 區界轉換

先確認 ZIP 原始雜湊與安全路徑，再讀取 SHP、SHX、DBF、CPG 及 PRJ。離線 pyproj／PROJ 採明確東距／北距輸入及經度／緯度輸出，不自行近似投影。保留多部件、內環及行政屬性；錯誤 CRS 或無效幾何中止發布，不默默修補。

實際接受 12 個有效多邊形，拒絕 0、修補 0；原始版次均為單部件且無內環，多部件／洞由合成測試另行驗證。所選轉換操作標示精度為 1 公尺，與原始區界及設施位置精度不同。全頂點往返最大誤差約 `1.8563 × 10⁻⁹` 公尺，小於 0.001 公尺容許值。`(250000,0) → (121°,0°)` 是投影原點解析測試，不能冒充獨立實測控制點；目前沒有經獨立測量的本地位置控制證據。

另有 11 組原始多邊形微小重疊，面積約 0.00001029 至 0.4074735 平方公尺，保留並記錄而未修補。因此個別幾何有效不等於區界完全無重疊；多重匹配仍列歧義。

## 6. 點位與區界判定

各筆保留來源行政區、區界判定行政區、所有匹配、區界距離、版本及分歧。狀態區分內部、邊界、外部、多重匹配及非法座標；共享邊界不能任意歸區。來源區名與區界不一致，代表待查分歧，不能直接判定來源座標錯誤。

3,305 列熱點在 25 公尺研究容差下為內部 3,174、邊界鄰近 119、外部 12；64 列來源／區界行政區不一致。熱點有 200 組重複座標，不能當作各自獨立的實體裝置。嚴格設定排除容差內位置；標示設定保留合格位置並揭示不確定性。10／25／50 公尺是研究參數，並非已測得誤差範圍。

## 7. 設施座標假設

B、D 暫以 EPSG:4326 解讀，C 的九列全數以 EPSG:3826 轉至 EPSG:4326，再查驗區界與身分。C 九列通過本次假設下的幾何檢查，並未因此取得官方 CRS 認證。EPSG:3828 的替代解讀亦被記錄；僅靠行政區歸屬不能排除相近基準。離線環境未有符合非概略要求的 EPSG:3828 → EPSG:4326 操作，故替代解讀未作正式入模依據。

官方設施目錄提供名稱／地址脈絡，沒有提供獨立測量座標或完整原始 datum 證明。通過數值範圍、地址與區界一致性，仍是明示假設下的研究資格。逐列假設、原始座標與欄位、排除及警告見[座標契約](wifi-allocation-v1.1-coordinate-contract.md)。

## 8. 設施身分

研究鍵限定於官方來源版次與名稱／地址複合身分；檢查空名稱、缺地址、相同複合鍵、相同地址、座標衝突與列鍵碰撞。不同資料集的相似名稱不自動合併，也不推論跨年身分連續。參考單位是通過版次內身分查核的官方設施紀錄，未聲稱是實地證實互異的公共場所。保留可能共址紀錄，才能看見分母的限制。

本次 `identityDiagnostics` 為空，未發現複合身分重複或列鍵碰撞；這不等於已由現場調查證明沒有跨來源共址。

## 9. 座標證據分層

「已驗證」需要權威來源 CRS 證據，加上轉換、幾何與身分通過。「假設檢驗通過」明確保留未確認的 CRS／精度契約，僅容許進行實驗。「未解」缺少必要條件，保留稽核但不產生模型增益。沒有虛構信心百分比。

| B 圖書館 | 70 | 0 | 69 | 1 |
| C 活動中心 | 9 | 0 | 9 | 0 |

91 列均可取得單一多邊形歸屬，但四列仍不合格。士林分館來源地址無法取得必要來源區名；三筆運動中心來源／多邊形區名分歧，分別為中正／大安、南港／信義、中山／大同。這是排除待查原因，不是四個設施不存在的證明。25 公尺內邊界鄰近設施為 0。

## 10. 模式 B 參考與候選群體

方法為 `wifi-geographic-proximity-experiment-v1`。H 是符合研究資格的已公布熱點座標位置，同座標合併為位置但保留所有來源 ID。R 是當次證據／地理／類別設定通過的設施紀錄；C 與 R 使用相同群體，因此 C = R。只接受已驗證時，分母與候選均為 0；接受假設檢驗通過時，合併群體為 87。依來源分別為圖書館 69、活動中心 9、運動中心 9。這些群體不同，不能把原始數量當作等量居民需求。

## 11. 幾何近鄰定義

使用平均地球半徑 6,371,008.8 公尺的球面 Haversine 距離；小於或等於研究門檻即為幾何鄰近。基準值計算 R 中有至少一個合格 H 位於門檻內的紀錄數。新增關聯只計尚未被基準或既選候選關聯的不同參考 ID。原始配對與距離離線計算，React 呈現時不重新進行全量 GIS 運算。

100／250／500 公尺均為分析參數，不是無線電訊號半徑。地圖圓標示「假設性幾何研究半徑」。幾何近鄰不能證明室內可收訊、網路正常、居民獲得服務或改善數位近用。

## 12. 候選與參考相同的平凡結果

因 C = R，選取尚未鄰近既有熱點的候選，必然以零距離將自己列入參考關聯。這是自我關聯，不是政策成效。模型分開報告自身、其他參考與總新增關聯；沒有額外非自身關聯時，顯示最佳化不可用並採可重現描述順序。全部參考已鄰近時新增為零。全部名額沒有取捨，也不能宣稱求得有效優先順序。

## 13. 情境策略

「邊際參考近鄰」逐次重算尚未關聯的其他參考紀錄貢獻，以穩定 ID 解決同分。「地理代表性」依有效行政區的已選數優先，再依邊際貢獻及 ID 排序；類別是輸出描述，沒有額外類別平衡。沒有主觀需求權重。代表性只描述行政區，並非人口公平或數位弱勢指標。

若資料只產生自身關聯，邊際策略明確回退為穩定 ID 描述順序；地理代表性仍可分散行政區查核名額，但不能宣稱帶來幾何服務增益。這項降級是研究發現，後續需更有根據且與候選相互獨立的參考分母，才適合解讀近鄰最佳化。

## 14. 5／10／全部名額

實用名額為需求上限與合格數較小者。「全部」代表全部合格調查紀錄，不代表全數設置設備。每個情境保留依序 ID、來源版次、合格／排除數、行政區與類別、基準及新增參考關聯、選取理由與不可用指標。完整依序名單見 `scenario-summaries.json` 及頁面 JSON／CSV 匯出；不能只以名稱跨版次認定同一設施。

## 15. 敏感度假設

比較已驗證／包含假設檢驗通過、100／250／500 公尺、嚴格／標示地理資格、10／25／50 公尺區界容差、B／C／D／合併群體、三種名額及兩策略。比較新增、移出、共同 ID、分母、基準、新增關聯及行政區／類別差異。同一快照／幾何版本才可比較。

零已驗證是有效結果。接受假設才形成 87 列群體，所以實驗分母依賴未確認 CRS；名單不變不能消除這一不確定性。距離增加會改變基準幾何關聯，也不代表訊號變強。無變化時如實報告，不能為展示效果製造差異。

## 17. 效能與驗證

GIS 全部離線執行，瀏覽器只讀靜態產物；模式 B 請求獨立延遲載入。地圖限制標記量，表格提供等價資訊。使用 Python 3.12、pyproj 3.7.2、Shapely 2.1.2、pyshp 2.3.1，版本固定於 `requirements-geographic.txt`。安裝後執行 `npm run data:build:wifi-geographic`；完整重現指令見[方法](wifi-allocation-v1.1-methodology.md)。

交付報告記錄實際執行的原始雜湊不變、重建決定性、座標／幾何／解析／情境測試、`./init.sh`、建置、桌面／手機中英文、匯出與主控台檢查。檔案與 gzip 大小、延遲 JS 與本機計算時間均須引用實測，不能當成公開主機延遲保證。本文不將待執行項目宣稱通過。

## 18. 限制與未來營運證據

CRS 轉換正確不代表原始設施位置準確。91 列不等於已確認互異且營運中的 91 個場所；87 列是有條件的研究分母。區界為歷史版次，設施資料不保證當日開放。官方中文名稱缺少可靠英文對應時，英文介面保留來源名稱，但控制與說明維持英文。

模式 C 仍缺營運狀態、實測品質、可比使用量、共同時間窗、連續站點身分及合適人口／需求分母。現場亦需確認可進入性、時段、建物遮蔽、電力、回程網路、安裝與管理權限。沒有推論訊號涵蓋、居民受益、數位排除或建置可行性。未來 Case Study 008 可展示來源治理、可重現 GIS、明示假設與平凡模型的誠實降級，不能包裝成已落實的城市服務成效。
